# Tesla Assistant

A mobile-first PWA for Tesla owners to track Safety Score, optimize charging, and get product recommendations.

## Features

- **Safety Score Tracker** - Monitor your Tesla Safety Score v2.2 with factor breakdown
- **Charging Optimizer** - Naples, FL Supercharger locations with real-time pricing
- **Product Recommendations** - Curated Tesla accessories by impact level

## Tech Stack

- React 18 + TypeScript
- Vite
- Lucide Icons
- PWA-ready

## Getting Started

```bash
# Install dependencies
npm install

# Development
npm run dev

# Build
npm run build

# Preview
npm run preview
```

## Deployment

```bash
# Build and deploy to Vercel
npm run build
vercel deploy --prod
```

## OpenClaw Integration

This app was built with OpenClaw and can be enhanced with:
- Automated Safety Score polling
- Charging price alerts
- Proactive notifications
